# Отчёт по проекту (РК) — Категоризация e-commerce товаров

## 1. Задача и метрика
Предсказать `category_ind` товара по контенту (текстовые поля, картинка, URL).
Категории заданы деревом (`tree.csv`), у товара ровно одна категория-лист.
Метрика соревнования — **macro F1-score** (равный вклад всех классов).

## 2. EDA (см. `docs/generated/`)
- Объектов в train: **111 405**; уникальных классов: **207**.
- Дисбаланс **31 563×**: самый частый класс — 31 563 примера; **7** классов с
  единственным примером, **30** классов с ≤5 примерами.
- Заполненность полей: `url` и `image_url` — **100%**, `vendor` пуст лишь у 6%,
  тогда как `name` пуст у **44%**, `description` — у **65%**, `type_prefix` — у 83%.
- **Вывод:** macro-F1 ограничен длинным хвостом редких классов; самые надёжные
  сигналы — `vendor`, домен/URL и **картинка** (доступна у всех товаров),
  поэтому в решении важны и текстовые, и картиночные признаки.

Графики: `class_distribution_log.png`, `root_distribution.png`,
`text_length_hist.png`, `missing_rate.png`, `top_domains.png`, `tree_depth.png`.

## 3. Идея решения и архитектура модели
Признаки строятся из объединённого текста `full_text` (с маркерами полей,
доменом и токенами URL). Линейка моделей по нарастанию качества:

1. **TF-IDF (word) + SGD** — baseline.
2. **TF-IDF (word + char_wb) + SGD/SVM** — устойчивее к опечаткам/морфологии.
3. **E5 (multilingual) эмбеддинги текста + LogReg** — семантика.
4. **Late fusion: E5 + CLIP (картинки) → MLP** — добавляет визуальный сигнал.
5. **Ансамбль** — смешивание вероятностей всех моделей.

Борьба с дисбалансом: `class_weight="balanced"`, аккуратный сплит редких
классов, использование иерархии дерева (`models/hierarchy.py`,
маскирование вероятностей по предсказанному корню) и per-class смешивание.

## 4. Воспроизводимость и трекинг
- Весь эксперимент запускается одним скриптом: `scripts/run_end2end.sh`
  (CPU, РК) и `scripts/train_full_pipeline.sh` (GPU, эмбеддинги).
- Зависимости зафиксированы: `pyproject.toml` (+ lock), extra `embeddings`.
- Код обработки данных — `src/.../data/prepare_dataset.py`; код обучения —
  `src/.../models/train_text_baseline.py` и `train_embedding_head.py`.
- **MLflow** логирует все параметры конфигов, метрики (accuracy, macro-F1) и
  модель; конфиги экспериментов — в `configs/experiments/*.toml`.

## 5. Результаты (Kaggle, macro-F1)
| Сабмишн | Что внутри | Public score |
|---|---|---|
| baseline | TF-IDF word по `name`+`vendor`, SGD | 0.288 |
| run03 | + `description`, домен и токены URL | 0.364 |
| run05 | TF-IDF word+char, LinearSVC | 0.363 |
| run06 | TF-IDF word+char, SGD, `class_weight="balanced"` | 0.387 |
| tfidf_v1 | подобранные гиперпараметры, обучение на полном train | 0.537 |
| ens_tfidf_e5 | TF-IDF + E5-LogReg | 0.574 |
| ens_3way_v2 | ансамбль трёх текстовых моделей | 0.582 |
| e5_clip_solo | late fusion E5 + CLIP → MLP | 0.699 |
| ens_4way_clip | + TF-IDF и E5-MLP в смесь | 0.709 |
| **ensemble_clip** | **blend TF-IDF : E5-LogReg : E5+CLIP = 1 : 2 : 1.5** | **0.723** |

Лучший результат — **0.723**, рост в 2.5 раза относительно первого бейзлайна.

Разбор прироста по этапам:
- **char-н-граммы** (0.364 → 0.387): устойчивость к опечаткам и морфологии
  русских названий товаров;
- **обучение на полном train + подбор гиперпараметров** (0.387 → 0.537);
- **семантические эмбеддинги E5** вместо разреженных признаков (→ 0.582);
- **картинки (CLIP)** — главный скачок, +0.12 (0.582 → 0.699). Это ожидаемо из
  EDA: изображение есть у 100% товаров, тогда как `name` пуст у 44%,
  а `description` — у 65%, то есть картинка часто единственный полный сигнал;
- **смешивание вероятностей** разнородных моделей (→ 0.723): веса 1 : 2 : 1.5
  подобраны по отложенной выборке.

Валидация: стратифицированный сплит с аккуратной обработкой редких классов
(классы с единственным примером целиком уходят в train). Offline macro-F1
модели `e5_clip` — 0.644 при public 0.699; расхождение объясняется тем, что
офлайн-метрика считается на более сложном хвосте после стратификации.

## 7. Выводы и дальнейшие шаги
- Главный резерв качества — редкие классы: oversampling/аугментация хвоста,
  отдельная обработка корневых категорий, калибровка порогов под macro-F1.

- Псевдоразметка хвостовых классов (zero-shot CLIP) для пополнения данных.
